# M1 · MVP offline trên Windows

Đưa các luồng offline của [M1 macOS](./20261128101843-m1-macos-offline.md) lên WinUI 3. Dùng chung Rust core, SQLite và fixture M0. Phần WinUI triển khai theo các task Windows M2 liên quan.

1. Triển khai lưu trữ, editor bền vững, tìm kiếm, ảnh và liên kết trong Rust core theo M1.1–M1.3 và phần dùng chung của M1.6–M1.7.
2. Tích hợp C ABI và adapter RichEditBox vào ứng dụng Windows. Giữ đường chạy fixture M0 để kiểm tra hồi quy.
3. Chạy kiểm thử trên DB thật, build WinUI và xác minh các luồng Windows. Ghi lại bằng chứng và cập nhật sổ nợ kỹ thuật.
