# Tạo dự án WinUI 3

**Phạm vi** — Tạo ứng dụng WinUI 3 cơ bản cho Windows bằng `winapp new`.

**Phụ thuộc** — Windows, .NET SDK và WinApp CLI. Dự án là nền tảng cho [prototype editor Windows M0.4](./m0-4-windows-editor-prototype.md).

## Tiêu chí nghiệm thu

- [x] Tạo dự án `Notes` từ template `winui` trong `clients/windows/Notes` bằng WinApp CLI `0.8.0` và template pack `0.0.8-alpha`.
- [x] Build Debug x64 bằng .NET SDK `11.0.100` với `dotnet build Notes.csproj -c Debug -p:Platform=x64`. Kết quả có 0 cảnh báo và 0 lỗi.
